## 💭 一些想说的话

我们做这个游戏，不是想让任何一个家长、老师或学生感到愧疚。

**我们只是想说：**

- 成绩、排名、荣誉——这些都不是一个孩子价值的全部。
- "坚持一下就好了"这句话，有时候不是鼓励，而是另一种伤害。
- 一个孩子把数学从"热爱"变成"焦虑"，往往只差一句"你怎么才考这点分"。
- 当孩子说"我没事，就是有点累"的时候，请多问一句："最近有什么开心的事吗？"

**如果你也常常觉得自己"不够好"——**

- 你已经很努力了。真的。
- 去为你真正喜欢的事情努力，而不是为别人的期待而活。
- 允许自己休息，允许自己发呆，允许自己做一些"没用"的事。
- 你的价值，不取决于任何一次考试。

**如果你身边也有像林知易一样的朋友——**

- 请多问一句："你最近还好吗？"
- 请多留一点耐心，多给一个拥抱。
- 有时候，一句"我在这里"，就足以把一个站在悬崖边上的人拉回来。

## 🛠 技术栈

- **纯前端**：HTML5 + CSS3 + Vanilla JavaScript
- **音频解谜**：Web Audio API（实时合成摩斯密码音效）
- **无外部依赖**：无框架、无库、无 CDN，完全离线可运行
- **响应式布局**：适配桌面浏览器（建议 1200px 以上宽屏体验）
